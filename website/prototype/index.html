PROTOTYPE HANDOFF

用 Axure 表达权限、状态和异常流程

GitHub 不能直接预览 Axure 源文件，因此最终交付必须同时包含可编辑源文件、HTML、关键截图和说明。

必做页面

  1. 带客户和时间筛选的反馈列表。
  2. 导出入口与字段说明。
  3. 无权限状态。
  4. 处理中状态。
  5. 下载完成状态。
  6. 失败与安全重试状态。

关键交互

  • 导出确认页保留当前客户和日期范围。
  • 无权限用户不能开始导出。
  • 确认页显示包含字段和内部备注排除规则。
  • 处理中状态可以迁移到完成或失败。
  • 失败状态说明原因并允许安全重试。

交付结构

prototype/
|-- source/pm-decision-flow.rp
|-- html/
|-- screens/
`-- notes.md

发布规则

  • 不上传假截图或复制付费模板。
  • 不放真实客户数据。
  • HTML 导出必须可以本地打开。
  • 完成后从案例页和仓库 README 链接可点击原型。
